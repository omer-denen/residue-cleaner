## 1. Bu oturumda kapanan iş — B24: denetim filtresi + dışa aktarma (commit `fd87707`)

**Kullanıcı isteği:** Kasa > Denetim sekmesinde `/api/audit` parametrelerini
(`since`, `kind`) arayüze bağlamak ve kayıtları CSV/JSON olarak indirmek.

### Motor (saf TS, yeni dosya)

- `src/core/audit-export.ts` — `AUDIT_EXPORT_LIMIT = 500`, `normalize()`
  (inceleme nesnesi → CSV/JSON satır modeli), `toCsv()`, `toJson()`.
- CSV: `\r\n` satır sonu, **BOM varsayılan açık**, sütun sırası
  `at,event,kind,ok,path,paths,bytes,code,reason`; `at` **ISO 8601**,
  `ok` **true/false** (TR "başarılı" değil), `paths` **`; `** ile birleşik;
  kaçış kuralı RFC 4180 (`"` çiftlenir, `,`/`;`/satır sonu içeren alan tırnaklanır).
- JSON: `{"version":1,"count":n,"records":[…]}` — kayıtlar `paths` + `counts`
  dahil ham modele yakın (kayıp alan yok).
- `paths` sütunu bilerek eklendi: tablo "Yol / hedefler" gösteriyor; çok hedefli
  silme kaydında `path` boş kalır, bilgi `paths`'te durur.

### Arayüz

- `web/src/screens/Vault.tsx`: Denetim sekmesine iki çip satırı — zaman
  (`Tümü / 1 saat / 24 saat / 7 gün / 30 gün`) ve tür (`Tümü / silme /
  geri yükleme / kalıcı silme / diğer`); `aria-pressed` ile seçim bildirilir;
  mevcut `kind-tabs` + `chip` sınıfları kullanıldı (yeni CSS yok).
- Filtre **sunucuda** çalışır: `loadAudit()` → `api.audit({ since, kind, limit })`.
- Dışa aktarma iki düğme: `CSV indir` / `JSON indir`; dosya adı
  `residue-denetim-YYYY-MM-DD.csv|json`; `Blob` + `createObjectURL` +
  geçici `<a download>` (ağ isteği yok, sunucuda yeni uç yok).
- **Dürüstlük notu:** sunucu limiti 500'dür; liste 500'e ulaşırsa
  `audit.export.truncated` ("En yeni 500 kayıt") satırı görünür ve not filtre
  değişince sıfırlanır.
- `web/src/i18n.ts`: 18 yeni anahtar × 2 dil (`audit.since.*`, `audit.kind.all`,
  `audit.export.*`, `audit.export.col.*`).

### Test

- `tests/audit-export.test.ts` (yeni, **16 test**): normalize, ISO/BOM, RFC 4180
  kaçış (noktalı virgül + virgül + satır sonu), `ok` boolean, `paths` birleştirme,
  boş liste, JSON şeması, tavan sabiti.
- `tests/shell-boundary.test.ts`: **tek dosya istisnası** (`audit-export.ts`) +
  gerekçe yorumu — web `src/core/audit-view.ts`'i import edemez (kural 18),
