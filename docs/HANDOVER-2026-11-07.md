     (Unix shim’ini Node ile çalıştırır → `SyntaxError`). Doğrusu:
     `.\node_modules\.bin\residue.cmd --version` veya `npx`.
2. **2FA:** `npm login --auth-type=web` başarılı olsa da publish
   `403 Two-factor authentication or granular access token with bypass 2fa
   enabled is required` verdi. Çözüm: bypass 2FA yetkili granular token
   kullanıldı; token 07.11.2026’da kullanıcı düzeyi `C:\Users\Code\.npmrc`
   içine kaydedildi (repo dışında; değeri belgelenmez). Web login tek başına
   publish için yetmez.

Ek not: yayından hemen sonra `npm view` bir süre `E404` döndü (CDN önbelleği).
`--prefer-online` veya cache-buster ile paket görünür oldu; bu bir yayın hatası
değildi.
